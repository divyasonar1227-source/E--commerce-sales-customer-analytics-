Zomato Restaurant Analytics Dashboard

Data Analytics Project Using Power BI

1. Project Overview

The Zomato Restaurant Analytics Dashboard is a data analytics project developed using Microsoft Power BI. It analyzes restaurant sales, orders, ratings, and city-wise performance using interactive charts and visualizations.

2. Project Objectives

  • Analyze total sales and total orders.
  • Identify the total number of restaurants.
  • Understand average restaurant ratings.
  • Compare sales across different cities.
  • Analyze orders by currency.
  • Compare sales by rating color.

3. Tools Used

  • Microsoft Power BI
  • Power Query
  • DAX, where applicable
  • CSV Dataset
  • HTML and CSS

6. Key Insights

  • The dashboard displays approximately 10K restaurants.
  • The displayed average rating is 2.67.

  • Green has the highest sales among the displayed rating colors.

7. Conclusion

The Zomato Restaurant Analytics Dashboard helps users understand restaurant data through visual reports. It provides insights into sales, orders, ratings, and city-wise performance. This project demonstrates practical skills in data analysis and dashboard development using Microsoft Power BI.
