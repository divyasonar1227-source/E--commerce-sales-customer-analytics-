Project Title

Zomato Restaurant Analytics Dashboard Using Power BI

1. Project Overview

The Zomato Restaurant Analytics Dashboard is a data analytics project developed using Microsoft Power BI. The project focuses on analyzing restaurant data to understand sales performance, order distribution, restaurant availability, ratings, and city-wise sales trends. Interactive charts, cards, and slicers are used to present the data in a simple and visual format. This dashboard helps users explore restaurant-related data and identify important business insights.

2. Project Objectives

- To analyze total sales and total orders.
- To identify the total number of restaurants.
- To understand the average restaurant rating.
- To compare sales performance across different cities.
- To analyze order distribution by currency.
- To compare sales based on rating colors.
- To provide interactive filtering using the City slicer.

3. Tools Used

- Microsoft Power BI – Dashboard creation and data visualization.
- Power Query – Data cleaning and transformation.
- CSV Dataset – Source data for analysis.
- DAX – Calculations and measures, where applicable.

4. Dashboard Features

- Total Sales: Displays the overall sales value.
- Total Orders: Shows the total number of orders.
- Total Restaurants: Displays the number of restaurants analyzed.
- Average Rating: Shows the average rating value.
- City-wise Sales Analysis: Compares sales across different cities.
- Orders by Currency: Visualizes order distribution by currency.
- Sales by Rating Color: Compares sales across rating color categories.
- City Slicer: Allows users to filter the dashboard by city.

5. Key Insights

- The dashboard displays approximately 10K restaurants.
- The average rating shown is 2.67.
- Jakarta and New Delhi appear among the leading cities in the city-wise sales chart.
- Green represents the highest sales category in the rating-color chart.
- Indian Rupees account for the largest share in the currency distribution chart.

Note: These observations are based on the displayed dashboard. Exact values should be verified against the source dataset.

6. Conclusion

The Zomato Restaurant Analytics Dashboard provides a visual overview of restaurant-related sales, orders, ratings, and city-wise performance. Power BI charts, cards, and slicers make it easier to explore the dataset and compare different categories. This project demonstrates practical skills in data visualization, data analysis, and dashboard development using Power BI.

7. Skills Learned

- Data Cleaning and Transformation
- Data Visualization
- Power BI Dashboard Development
- Basic DAX Calculations
- Business Data Analysis
- Interactive Report Design
